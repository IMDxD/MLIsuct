## 🛠️ Правила написания кода (PyTorch)

1.  **Контроль устройств (Device-agnostic code):** 
    Всегда пишите код с поддержкой CUDA/MPS/CPU. Don't hardcode `cuda`.
    ```python
    device = torch.device("cuda" if torch.cuda.is_available() else "mps" if torch.backends.mps.is_available() else "cpu")
    model = MyModel().to(device)
    ```
2.  **Воспроизводимость (Seed):** 
    В начале ноутбуков/скриптов всегда фиксируйте random seed.
    ```python
    torch.manual_seed(42)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(42)
    ```
3.  **Использование DataLoader:** 
    Для загрузки данных всегда используйте `torch.utils.data.Dataset` и `DataLoader` с параметром `num_workers` и `pin_memory=True` (если используется GPU).
4.  **Чистота пайплайнов:** 
    Разделяйте код на логические блоки: подготовка данных, архитектура модели, шаг обучения (`train_step`), шаг валидации (`val_step`) и цикл обучения (`training loop`).
